日ノ本鯖（以下、「当サーバー」）の運営チームが提供するDiscordボットおよびWeb認証システム（以下、「本システム」）における、ユーザーの情報の取り扱いについて定めます。

:::note[はじめに]
本システムを利用してDiscordサーバーに参加、または認証を行うことにより、本プライバシーポリシーに同意したものとみなされます。
不明な点やご質問がある場合は、運営チーム（チケット等）にお問い合わせください。
:::

## 1. 取得する情報とその目的

本システムでは、サーバーの円滑な運営、スパム・マルチアカウント対策、およびセキュリティ維持のために以下の情報を取得・利用します。

| 取得する情報 | 利用目的 |
| --- | --- |
| **Discordアカウント情報**（ユーザーID、ユーザー名等） | 認証状態の確認、メンバーロールの付与、不正対策、ブラックリスト判定 |
| **アクセス元IPアドレス** | VPN・プロキシ等の不正アクセスの検出、セキュリティブロック判定 |
| **アカウント作成日時** | 作成後7日未満のサブアカウント・スパムの自動検知 |
| **警告履歴・モデレーション履歴** | サーバー内のルール違反状況の管理、運営用スレッドでの対応 |
| **チケットおよび問い合わせ履歴** | サポート対応、不正報告・補償相談の履歴管理、ログ保存（トランスクリプト） |
| **誕生日データ**（希望者のみ） | 当日の祝福アナウンス機能の実行 |

## 2. 情報の利用制限と管理

- 取得した個人情報やIPアドレス等は、当サーバーのセキュリティ維持および運営目的以外には利用しません。
- 法律に基づく公的機関からの開示請求など、正当な理由がある場合を除き、取得した情報を第三者に開示・提供することはありません。
- セキュリティリストや警告履歴などのデータは、Discord内の管理用プライベートチャンネル等で厳重に保管・バックアップされます。

## 3. reCAPTCHAの利用について

本システムのWeb認証ページでは、スパムやボットによる自動攻撃を防ぐために Google が提供する **reCAPTCHA v2** を利用しています。
- reCAPTCHAの使用は、Googleの[プライバシーポリシー](https://policies.google.com/privacy)および[利用規約](https://policies.google.com/terms)が適用されます。
- 入力されたハードウェア・ソフトウェア情報（IPアドレスやブラウザ情報など）は、Googleへ送信され、ロボットではないことの判定にのみ使用されます。

## 4. ユーザーの権利とデータ削除について

- **情報の確認・削除:** 自身に関するデータの確認や、運営管理データからの削除申請が必要な場合は、お手数ですが運営用チケットにてお問い合わせください。
- ただし、サーバーのセキュリティやモデレーションの維持に不可欠なデータ（重大な処罰・ブラックリスト履歴など）については、削除に応じられない場合があります。

## 5. プライバシーポリシーの改定

当サーバーは、法令の変更やシステム機能の追加・変更に伴い、本プライバシーポリシーを予告なく改定することがあります。重要な変更がある場合は、Discordサーバー内でお知らせします。
