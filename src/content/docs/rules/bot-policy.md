日ノ本鯖（以下、「当サーバー」）の運営チームが提供するDiscordボットおよびWeb認証システム（以下、「本システム」）における、ユーザーの情報の取り扱いについて定めます。

:::note[はじめに]
本システムを利用してDiscordサーバーに参加、または認証を行うことにより、本プライバシーポリシーに同意したものとみなされます。
不明な点やご質問がある場合は、運営チーム（チケット等）にお問い合わせください。
:::

## 1. 取得する情報とその目的

本システムでは、サーバーの円滑な運営、スパム・マルチアカウント対策、およびセキュリティ維持のために以下の情報を取得・利用します。

| 取得する情報 | 利用目的 |
| --- | --- |
| **Discordアカウント情報**（ユーザーID、ユーザー名等） | 認証状態の確認、メンバーロールの付与、不正対策、ブラックリスト判定 |
| **アクセス元IPアドレス** | VPN・プロキシ等の不正アクセスの検出、セキュリティブロック判定 |
| **アカウント作成日時** | 作成後7日未満のサブアカウント・スパムの自動検知 |
| **警告履歴・モデレーション履歴** | サーバー内のルール違反状況の管理、運営用スレッドでの対応 |
| **チケットおよび問い合わせ履歴** | サポート対応、不正報告・補償相談の履歴管理、ログ保存（トランスクリプト） |
| **誕生日データ**（希望者のみ） | 当日の祝福アナウンス機能の実行 |

## 2. 情報の利用制限と管理

- 取得した個人情報やIPアドレス等は、当サーバーのセキュリティ維持および運営目的以外には利用しません。
- 本システムの提供に必要な範囲で、認証・運営記録にDiscord、アクセス元の判定にproxycheck.io、ボット対策にGoogleのreCAPTCHAを利用します。これらのサービスへの送信内容は以下に記載します。法令に基づく開示などを除き、それ以外の目的で情報を第三者へ開示・提供しません。
- セキュリティリストや警告履歴は、運営記録用に設定したDiscordチャンネルへ保存します。認証の成功・拒否時には、Discordのユーザー名・ID・IPアドレスを指定の管理者へのDMに記録し、拒否時は設定したログチャンネルにも記録します。
- チケットの会話履歴は、トランスクリプトの保存操作によってDiscord上へ保存します。誕生日は登録者のDiscord IDと月日をボットの稼働中のメモリーに保持します。
- 運営記録の保存先は担当スタッフ以外が閲覧できないよう管理します。

### IPアドレス判定サービスへの送信

VPN・プロキシなどのアクセス元を判定するため、認証時のアクセス元IPアドレスを **proxycheck.io** へ送信します。判定結果を認証の許可・拒否に利用します。
Googleへの送信については、次の節を確認してください。

## 3. reCAPTCHAの利用について

本システムのWeb認証ページでは、スパムやボットによる自動攻撃を防ぐために、Googleが提供する **reCAPTCHA v2** を利用します。

- 認証に伴い、IPアドレスやブラウザー情報などがGoogleへ送信され、リスク分析のためのCookieが使用されます。
- Googleによる処理の目的は、サービスの提供・維持と、セキュリティ・不正利用防止のための脅威検知・保護・対応です。「ロボットではないことの判定」だけに限られるものではありません。
- データの処理には、[Google Cloud利用規約](https://cloud.google.com/terms)、[Cloudデータ処理に関する追加条項](https://cloud.google.com/terms/data-processing-addendum)、[サービス固有の規約](https://cloud.google.com/terms/service-terms)が適用されます。

Googleの取扱いについては、[reCAPTCHAのデータ処理に関する公式説明](https://docs.cloud.google.com/recaptcha/docs/faq#data_processing)も確認できます。

## 4. ユーザーの権利とデータ削除について

- **情報の確認・削除:** 自身に関するデータの確認や、運営管理データからの削除申請が必要な場合は、お手数ですが運営用チケットにてお問い合わせください。
- ただし、サーバーのセキュリティやモデレーションの維持に不可欠なデータ（重大な処罰・ブラックリスト履歴など）については、削除に応じられない場合があります。

## 5. プライバシーポリシーの改定

当サーバーは、法令の変更やシステム機能の追加・変更に伴い、本プライバシーポリシーを予告なく改定することがあります。重要な変更がある場合は、Discordサーバー内でお知らせします。
