日ノ本鯖（以下、「当サーバー」）の運営チームが提供するDiscordボットおよびWeb認証システム（以下、「本システム」）を利用するすべてのユーザーに適用される利用規約を定めます。

:::note[はじめに]
本サービスを利用することにより、本利用規約のすべてに同意したものとみなされます。規約は運営の判断により予告なく改定されることがありますので、最新の内容をご確認ください。
:::

## 1. 適用範囲と目的

- 本規約は、当サーバーへの参加、Web認証、チケット機能、およびボットが提供するすべての機能を利用するユーザーに適用されます。
- ユーザーは、サーバーのルールおよびDiscordの利用規約を遵守するものとします。

## 2. 禁止事項

本サービスの利用にあたり、以下の行為を禁止します。違反した場合は、警告、タイムアウト、キック、BAN、またはブラックリストへの登録など、運営の判断により必要な処置を行います。

| 禁止行為 | 内容 |
| --- | --- |
| **不正アクセス・セキュリティ回避** | VPNやプロキシ等を使用した認証回避、ボットの脆弱性を突く行為 |
| **スパム・マルチアカウント** | 短期間での大量の参加・メッセージ送信、サブアカウントによる規約逃れ |
| **嫌がらせ・迷惑行為** | 他のユーザーや運営に対する暴言、誹謗中傷、荒らし行為 |
| **チケットの不正利用** | 悪質な虚偽の申請、嫌がらせ目的での連続したチケット作成 |
| **その他** | 法令やDiscord利用規約に違反する行為、運営の指示に従わない行為 |

## 3. アカウントおよび認証について

- サーバーへの参加には、Web認証およびセキュリティチェック（reCAPTCHA等）の通過が必要です。
- 作成から日の浅いアカウントや、サブアカウントと判定された場合は参加が制限される場合があります。
- 不正が検知された場合、事前の通知なくロールの剥奪やアクセス拒否（BAN・ブラックリスト登録）を行うことがあります。

## 4. 免責事項

- 運営チームは、システムのメンテナンス、障害、あるいは第三者の攻撃等によって本サービスが停止・中断した場合にユーザーに生じた損害について、一切の責任を負いません。
- 提供されるコマンドや機能（マイクラサーバー連携、スコアボード、チケット、おみくじ等）の動作や正確性について、完全性を保証するものではありません。
- ゲーム内のアイテム損失、データ消失、トラブル等について、運営は原則として補償を行いません。

## 5. 規約の変更

当サーバーは、必要に応じて本規約をいつでも変更できるものとします。変更後の規約は、当サーバー内または公式ドキュメントに掲示した時点で効力を生じるものとします。
